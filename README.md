# VK Video Live — скачать чат записи (VOD)

Tampermonkey-скрипт, который добавляет на страницы записей [VK Video Live](https://live.vkvideo.ru) кнопку **«↓ Скачать чат»** и выгружает весь чат VOD одним файлом.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (или Violentmonkey).
2. Откройте `vkvideo-vod-chat-downloader.user.js` — менеджер предложит установить скрипт.

## Использование

Откройте запись вида `https://live.vkvideo.ru/<канал>/record/<uuid>` (можно с `?tab=video`). В правом верхнем углу чата, под шапкой, появится кнопка. Нажмите её и выберите формат:

| Формат | Содержимое |
|---|---|
| **TXT** | читаемый лог `[1:23:45] Nick: текст` с ответами, `@упоминаниями`, `:смайлами:` и пометкой удалённых |
| **CSV** | таблица для Excel (разделитель `;`, UTF-8 с BOM) |
| **JSON** | сырые объекты API: автор, бейджи, роли, родительские сообщения |

Пока идёт загрузка, на кнопке виден прогресс. Повторный клик отменяет загрузку. Загруженный чат кэшируется, поэтому другой формат скачивается без новых запросов.

## Как это работает

Скрипт обращается к тому же эндпоинту, что и сайт:

```
GET https://api.live.vkvideo.ru/v1/channel/<канал>/record/<uuid>/chat/?time_code=T&limit=200
```

Каждый ответ содержит до 200 сообщений до `T` и до 200 после. Скрипт начинает с `T=0`, на каждом шаге переносит `T` на максимальный `timeCode` из правой половины ответа и отбрасывает повторы по `id`. Работа заканчивается, когда после `T` сообщений больше нет. Запросы отправляются с cookies, поэтому записи для подписчиков тоже выгружаются, если вы залогинены.

## Настройки

Константы в начале скрипта:

- `CORNER` — угол чата для кнопки (`top-right`, `bottom-right`, `top-left`, `bottom-left`);
- `OFFSET`, `HEADER_ZONE` — отступ от края и высота полосы, которая считается шапкой чата;
- `CHAT_SELECTORS` — селекторы контейнера чата. Если кнопка встала не туда, добавьте первым точный селектор из DevTools;
- `DELAY_MS` — пауза между запросами;
- `CSV_SEP` — разделитель CSV.

## Ограничения

- Классы на сайте хэшированные, поэтому контейнер чата ищется эвристически. Если его не найти, кнопка встаёт в угол окна.
- Скрипт опирается на неофициальный API. Если сайт его изменит, скрипт придётся обновить.
